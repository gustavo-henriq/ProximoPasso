# E agora, qual é o próximo passo?

Guia interativo de orientação profissional para estudantes do Ensino Médio. O site é estático e não precisa de back-end.

## Abrir localmente

Com Python instalado, abra um terminal nesta pasta e execute:

```powershell
python -m http.server 4173
```

Depois abra http://127.0.0.1:4173 no navegador.
